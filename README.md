# University Explorer 🎓

University Explorer is a simple web application that helps users explore and learn about different universities. The project presents university information in a clean and structured interface using HTML, CSS, and JavaScript.

## 🚀 Features

* View information about different universities
* Clean and responsive user interface
* Dynamic content using JavaScript
* Simple and lightweight web application

## 🛠️ Tech Stack

* **HTML5** – Structure of the web page
* **CSS3** – Styling and layout
* **JavaScript** – Interactivity and dynamic behavior

## 📂 Project Structure

```
University-explorer
│
├── index.html     # Main webpage
├── style.css      # Styling for the website
├── script.js      # JavaScript functionality
└── README.md      # Project documentation
```

## ⚙️ How to Run the Project

1. Clone the repository

```
git clone https://github.com/ashishpagare22/University-explorer.git
```

2. Navigate to the project folder

```
cd University-explorer
```

3. Open the project

Simply open **index.html** in your browser.
